# Subscribe to webhooks

> 🚧 Subsequent Requests Will Override Previous Subscriptions
>
> Reap maintains only the latest subscription and tracks a single endpoint per client for webhook event delivery. Please note that Reap’s system will send webhooks only to the most recently subscribed server URL.
